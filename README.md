# 🔨 HammerHit

**정답 두더지만 때려라!** 영어 단어를 배우는 두더지 잡기 미니게임입니다.

- 📖 **뜻 찾기**: 한국어 뜻을 보고 맞는 영어 단어를 든 두더지를 때립니다.
- 🔊 **듣고 찾기**: 영어 발음을 듣고 맞는 단어를 든 두더지를 때립니다.
- 🌱🌿🌳 레벨 3단계, 단어 80여 개 (초등 기초 어휘)
- 🔥 콤보, 점점 빨라지는 두더지, 헷갈리는 오답 (`sheep` ↔ `ship`)
- 📒 오답 노트와 틀린 단어 복습 라운드, 단어별 숙련도 저장

## 실행

설치나 빌드가 필요 없습니다. `index.html`을 브라우저로 열면 됩니다.

로컬 서버로 띄우려면:

```bash
npm start   # python3 -m http.server 8000 → http://localhost:8000
```

> 듣고 찾기 모드는 브라우저 내장 음성(speechSynthesis)을 사용합니다. Chrome, Edge, Safari에서 동작합니다.

## 테스트

```bash
npm test    # Node 18+ 내장 테스트 러너
```

## 단어 추가

`js/words.js`에 한 줄을 추가하면 됩니다.

```js
w('sheep', '양', '🐑', 'animal', 1, ['ship']),
//  영어    뜻    그림   카테고리  레벨  헷갈리는 단어
```

설계 배경과 구조는 [docs/DESIGN.md](docs/DESIGN.md)에 정리되어 있습니다.
